## Pourquoi Multiplan ? (Le voyage dans le temps d'un quinqua) 😀
#
Ce projet est né d'une **émotion** : celle de retrouver, en 2026, le logiciel **Multiplan** avec lequel j'ai découvert l'informatique il y a **40 ans**. 
#
🛠️ Installation Rapide
#
Pour les nostalgiques, ouvrir le fichier : **Multiplan 1986 sous Windows 11 en 2026.pdf**
#
Le guide est complet et **tous les fichiers nécessaires** sont fournis. Le mode opératoire est relativement simple.
#
Alors que vous utilisez **Windows 11** en **2026** (un système 64 bits ultra-rapide), **Multiplan** tournait en **1986** dans un environnement 16 bits sous MS-DOS, sans souris, avec des disquettes que l'on insérait physiquement.
#
## En 2 heures de travail, vous remonterez le temps de 40 ans ! 
#
C'est tout ce **charme "vintage"** que ce projet vous permet de retrouver sur votre matériel moderne.
#
